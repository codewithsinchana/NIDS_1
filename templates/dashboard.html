Security Notes

This version generates software-based simulated traffic. The blocklist records simulated blocking decisions; it does not modify Windows Firewall rules or block real network traffic.

Use a unique SECRET_KEY and keep email credentials in environment variables. Do not publish demo credentials in a production deployment.
